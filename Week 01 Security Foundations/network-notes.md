|----------|------------|------------|----------|
| Router | 192.168.1.1 | 255.255.255.0 | Default Gateway |
| PC1 | 192.168.1.10 | 255.255.255.0 | Client Device |

## Connections

- PC1 connected to Switch
- Laptop connected to Switch
- Server connected to Switch
- Switch connected to Router
- Router connected to Internet
